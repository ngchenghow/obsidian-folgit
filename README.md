# Folgit

Minimal Obsidian plugin: prompts for text and echoes it back as a notice.

## Usage

Open the command palette and run **Echo input**. Type something, press Enter (or click OK), and it shows up as a notice.

## Install (manual)

1. `npm install`
2. `npm run build`
3. Copy `manifest.json` and the built `main.js` into `<your-vault>/.obsidian/plugins/obsidian-folgit/`.
4. Enable **Folgit** in Obsidian's Community plugins settings.
